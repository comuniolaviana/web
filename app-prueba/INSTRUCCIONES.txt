COMUNIO LAVIANA · APP PRUEBA V3

QUÉ CAMBIA EN ESTA VERSIÓN

1. CLÁUSULAS
- Separadas por:
  Porteros
  Defensas
  Medios
  Delanteros
- Dentro de cada posición: orden de MAYOR A MENOR CLÁUSULA.
- Cada jugador muestra:
  propietario
  equipo
  puntos
  valor actual
  cláusula
- El botón Ejecutar solo se activa si TODAS las reglas se cumplen.

2. REGLAS
- 1 cláusula pagada por usuario y jornada.
- 1 cláusula recibida por usuario y jornada.
- Cuando alguien recibe una cláusula, TODOS sus jugadores desaparecen.
- Día permitido según el CALENDARIO OFICIAL DE LA WEB.
- Horario estricto 15:00–21:00.
- datos.json tiene que estar actualizado HOY.
- No se puede ejecutar sobre un jugador propio.

3. CALENDARIO
NO HAY UN CALENDARIO DE PRUEBA SEPARADO.
La app abre ../index.html y lee directamente el objeto calendarioClausulas
que ya utiliza la página oficial.
Por tanto, si modificas el calendario en la web principal, la app utiliza
esa misma regla.

4. RESTO DE LA WEB DENTRO DE LA APP
- Equipo Malo
- Normas
- Copa
- Palmarés
- Estadísticas
- Fair Play

Estas secciones cargan las páginas REALES que ya están en la carpeta web.
No hay copias duplicadas dentro de app-prueba.

5. ACTUALIZACIÓN DIARIA
La app lee directamente:
  ../datos.json
  ../equipos.json
Por tanto tu rutina de actualización sigue siendo la misma.

IMPORTANTE
Sigue siendo un prototipo:
- el usuario todavía se elige en una lista, no entra por email;
- las ejecuciones se guardan solo en este dispositivo;
- falta la base de datos central para sincronizar todos los móviles.

CÓMO SUBIR
Sustituye TODO el contenido de:
  web/app-prueba/
por los archivos de este ZIP.
Después:
  Commit -> Push origin

NO hay que sustituir ningún archivo de la web principal para probar V3.
