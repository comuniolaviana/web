COMUNIO LAVIANA · PROTOTIPO V2

REGLAS YA INCLUIDAS
- Cada usuario puede PAGAR 1 cláusula por jornada.
- Cada usuario puede RECIBIR 1 cláusula por jornada.
- Cuando un usuario recibe una cláusula, TODOS sus jugadores desaparecen.
- Solo funciona en días abiertos del calendario.
- Solo funciona entre 15:00 y 21:00.
- Si datos.json no está actualizado HOY, NO se puede ejecutar ninguna cláusula.
- Fuera de horario el botón EJECUTAR está deshabilitado.
- No se puede ejecutar sobre un jugador propio.
- El mismo jugador no se puede ejecutar dos veces.
- Se vuelven a comprobar las reglas al confirmar.

ACTUALIZACIÓN DIARIA
La app NO lleva una copia propia de datos.json ni equipos.json.
Lee directamente:
  ../datos.json
  ../equipos.json
Por tanto, cuando actualices la web como haces normalmente, la app verá automáticamente los datos nuevos.

IMPORTANTE
Esto sigue siendo un PROTOTIPO:
- no hay login real por correo;
- no hay base de datos central;
- el historial se guarda solo en este dispositivo;
- aún no existe el bloqueo seguro entre dos móviles distintos.
La siguiente fase será servidor + usuarios + base de datos.
